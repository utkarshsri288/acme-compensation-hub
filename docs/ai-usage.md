# AI-assisted development notes

AI is being used as an accelerator and review partner, not as a substitute for product or engineering judgment.

- Product framing: used to structure the requirements, identify explicit non-goals, and turn the spreadsheet pain into testable workflows.
- Implementation: used to draft scaffolding, test cases, and UI copy; each generated change is reviewed against the requirements and local data model.
- Verification: tests, linting, manual browser checks, and data reconciliation remain the source of truth.
- Security boundary: no real employee data, credentials, or production secrets are supplied to AI tools.
