# ACME Salary Management

Employee salary management software for a 10,000-person organization. The product plan is available as a polished HTML artifact at [`planning/index.html`](planning/index.html), with the one-page requirements document at [`docs/requirements.md`](docs/requirements.md).

## Status

Planning phase complete. Implementation follows in incremental commits.

## Repository map

- `docs/requirements.md` — scope, user, MVP features, non-goals, success measures
- `docs/architecture.md` — system shape, API, data model, performance, quality, deployment
- `docs/ai-usage.md` — intentional AI usage and verification approach
- `planning/index.html` — visual product-planning artifact
- `backend/` — API and database implementation
- `frontend/` — React application
